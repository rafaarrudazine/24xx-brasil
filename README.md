# 24XX Brasil — site estático (v0.7.1)

Pronto para publicação por GitHub Pages. A pasta contém apenas material público autorizado.

## Publicar
1. Crie um repositório público `24xx-brasil` no GitHub.
2. Na raiz da branch `main`, envie **o conteúdo desta pasta**: `index.html`, `assets/`, `.nojekyll`, `robots.txt` e `README.md`. Não envie o ZIP como arquivo único.
3. Em Settings > Pages > Build and deployment: Source `Deploy from a branch`, Branch `main`, Folder `/(root)`, Save.
4. Acesse `https://SEU-USUARIO.github.io/24xx-brasil/` depois que o Pages publicar.

## Importante
- Os PDFs comerciais dos jogos 2400 não integram este pacote.
- As fichas de personagem são materiais de apoio independentes, não fichas oficiais.
- Todas as referências de PDF e imagens são relativas, para funcionar em um repositório de projeto do GitHub Pages.
- O site é estático; não precisa de Node, banco de dados, servidor de aplicação ou serviços pagos.
- Não disponibilize arquivos de pesquisa privada na raiz deste repositório.
